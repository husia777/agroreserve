## СТЕК ТЕХНОЛОГИЙ

### Backend

- **Python 3.11+** + **FastAPI** — REST API
- **MongoDB** (MongoDB Atlas или self-hosted) — основная БД
- **Motor** — async MongoDB driver
- **Pydantic v2** — валидация данных
- **Beanie** или **ODMantic** — ODM для MongoDB
- **Celery** + **Redis** — фоновые задачи (уведомления, отчёты, синхронизация с 1С)
- **JWT** — аутентификация (access + refresh tokens)

### Frontend

- **React 18** + **TypeScript**
- **Vite** — сборщик
- **TailwindCSS** — стили
- **React Query (TanStack Query)** — кэширование и синхронизация данных
- **React Hook Form** + **Zod** — формы и валидация
- **Zustand** — state management
- **React Router v6** — роутинг

### Интеграции

- **1С:Предприятие 8.3** — OData REST API (двусторонняя синхронизация: товары, остатки, документы, оплаты)
- **Telegram Bot API** — уведомления клиентам и админу, автопрайс
- **SMTP / Email** — уведомления, документы
- **Puppeteer / WeasyPrint** — генерация PDF (ТОРГ-12, счета, ярлыки, договоры)

### Инфраструктура

- **Nginx** — reverse proxy, SSL, static files
- **Docker** + **Docker Compose** — контейнеризация
- **Let's Encrypt** — SSL
- **VPS** (2 vCPU, 4 GB RAM, 80 GB SSD) — хостинг
- **MongoDB Atlas** (M10) или self-hosted MongoDB
- **Automated backups** — ежедневно MongoDB dump + файлы на S3/Яндекс.Облако

### Синхронизация с 1С

```
НАПРАВЛЕНИЕ: Двусторонняя

Веб → 1С:
  - Новый заказ → Реализация в 1С
  - Приходование товара → Поступление в 1С
  - Списание → Списание в 1С

1С → Веб:
  - Остатки товаров (каждые 5 мин или по событию)
  - Оплаты клиентов (при поступлении на р/с)
  - Справочники (номенклатура, контрагенты)

ПРОТОКОЛ: OData REST API 1С 8.3
ФОРМАТ: JSON
АУТЕНТИФИКАЦИЯ: Basic Auth (1С) + API Key
```

## РЕЕСТР ЮЗКЕЙСОВ (58 штук)

### 🔴 MVP — 22 юзкейса (запуск)

#### КАТАЛОГ

**UC-01: Просмотр каталога**

- Клиент видит товары с фото, ценой, описанием, наличием
- Фильтры: категория, поиск по названию
- Сортировка: по цене, по названию, по популярности
- Цена B2B отличается от розничной (видна только авторизованным B2B)
- Если товара нет — кнопка «Уведомить о поступлении»
- Адаптивная вёрстка (мобильный приоритет)

**UC-09: Остатки реалтайм**

- На карточке товара отображается актуальный остаток
- Синхронизация с 1С каждые 5 минут или при изменении
- Если остаток < минимального — показывать «Мало» или «Заканчивается»
- Если остаток = 0 — «Нет в наличии», кнопка заказа неактивна
- Остаток показывается в кг или штуках в зависимости от товара

**UC-24: Поштучный калькулятор**

- На карточке товара: поле ввода количества (кг) → мгновенный расчёт суммы
- Возможность ввести количество в штуках → пересчёт в кг по среднему весу
- Пример: «1 шт ≈ 150 г, 10 шт ≈ 1.5 кг = 52.5 ₽»
- Средний вес штуки задаётся админом для каждого товара

**UC-40: Мульти-категорийный каталог**

- Категории: Овощи, Фрукты, Сухофрукты, Орехи, Специи, Мёд, Масла
- Подкатегории опционально (Овощи → Корнеплоды, Листовые и т.д.)
- Иконка/фото для каждой категории
- Счётчик товаров в категории
- Древовидная навигация + хлебные крошки

#### АВТОРИЗАЦИЯ

**UC-02: Регистрация/авторизация**

- Регистрация: телефон + SMS-код (или Telegram), имя, тип (ИП/ООО/физлицо)
- Для B2B при регистрации: ИНН, название организации, юр. адрес
- Авторизация: телефон + SMS-код (или email + пароль)
- JWT: access token (15 мин) + refresh token (30 дней)
- После регистрации B2B — статус «На модерации» (не видит цены, не может заказывать)

**UC-14: Модерация клиентов**

- Админ видит список новых регистраций B2B со статусом «На модерации»
- Может: одобрить (→ клиент получает доступ к B2B ценам и заказам), отклонить, запросить доп. данные
- При одобрении — уведомление клиенту в Telegram/SMS
- Розничные клиенты (физлица) — автоодобрение

#### ЗАКАЗЫ

**UC-03: Заказ B2B**

- Клиент добавляет товары в корзину с указанием количества (кг)
- В корзине: список товаров, количество, цена за кг, сумма по позиции, итого
- Примечание к заказу (текстовое поле)
- Выбор даты и времени доставки (UC-41)
- Подтверждение заказа → статус «Новый»
- Уведомление админу (Telegram + email + звук в админке)
- Оплата: по факту (безнал для B2B) или предоплата
- В корзине показывается: «Итого по заказу», «Ваш кредитный лимит», «Задолженность»

**UC-41: Время и приоритет доставки**

- При оформлении заказа клиент выбирает:
  - Дату доставки (не раньше завтра, не позже +7 дней)
  - Временной слот: 08:00–11:00, 11:00–14:00, 14:00–17:00
- Админ видит заказы сгруппированные по дате и слоту
- Приоритет доставки: 🔴 Срочно (госконтракт), 🟡 Обычный, 🟢 Гибкий

**UC-60: Трекинг заказа для клиента**

- Статусы заказа: Новый → Подтверждён → Собирается → Собран → В пути → Доставлен
- Клиент видит текущий статус в ЛК с временной шкалой
- Push-уведомления при смене статуса (Telegram)
- При статусе «В пути» — ориентировочное время доставки

#### ДОКУМЕНТЫ

**UC-08: Скачивание документов из ЛК**

- Клиент в ЛК видит все документы по своим заказам
- Типы: Счёт, ТОРГ-12, УПД, Акт сверки, Сертификаты
- Скачивание в PDF одним кликом
- Фильтр по периоду, типу документа
- Кнопка «Скачать все документы за период» (ZIP)

**UC-49: Автодокументооборот**

- При подтверждении заказа → автогенерация: Счёт на оплату (PDF)
- При отгрузке → автогенерация: ТОРГ-12 (PDF), Этикетки/ярлыки
- Данные подтягиваются из: карточки клиента (реквизиты), заказа (товары, количество, цены), настроек (реквизиты ИП)
- Нумерация документов: автоинкремент по типу (Счёт-001, ТОРГ12-001)
- Печать: кнопка «Печать» открывает PDF для отправки на принтер
- Шаблоны документов — редактируемые (логотип, подпись, печать)

#### СЕРТИФИКАТЫ

**UC-21: Управление сертификатами**

- Админ загружает сканы сертификатов/деклараций (PDF/JPG)
- Привязка к товарам (один сертификат → несколько товаров)
- Поля: номер, тип (декларация ТР ТС, сертификат, ветсправка), дата выдачи, срок действия, орган выдачи
- Статусы: действующий, истекает скоро (< 30 дней), просрочен
- Хранение: MongoDB GridFS или S3

**UC-22: Печать ярлыков/сертификатов**

- Генерация ярлыка товара для наклейки на упаковку
- Содержание ярлыка: наименование, производитель, страна происхождения, масса, дата фасовки, срок годности, условия хранения, номер декларации
- Формат: A6 (для каждой упаковки) или несколько на A4
- Печать пакетом: выбрал товары → «Печать ярлыков» → PDF с ярлыками

**UC-23: Просмотр сертификатов клиентом**

- В карточке товара: ссылка «Сертификат соответствия»
- Клиент может просмотреть и скачать PDF сертификата
- В корзине/заказе: кнопка «Скачать все сертификаты» (ZIP)
- Для госзакупок: полный комплект сертификатов по заказу одной кнопкой

**UC-25: Управление единицами измерения и фасовками**

- Для каждого товара задаётся: основная единица (кг, шт, л), фасовки (мешок 25 кг, ящик 10 кг, поштучно)
- Средний вес штуки (для поштучного калькулятора)
- Минимальная партия заказа (например: картофель от 5 кг)
- Шаг изменения количества (0.1 кг, 0.5 кг, 1 кг)

#### ФИНАНСЫ

**UC-30: Кредитный лимит и дебиторка**

- Каждому B2B-клиенту назначается кредитный лимит (0–100 000 ₽)
- По умолчанию: 0 (предоплата)
- Дебиторская задолженность = сумма неоплаченных заказов
- Если задолженность >= лимит → блокировка новых заказов
- Уведомление клиенту: «Ваш кредитный лимит исчерпан. Оплатите задолженность для новых заказов»
- Уведомление админу: «Клиент X достиг кредитного лимита»
- Срок оплаты: настраивается (7/14/30 дней)
- Просрочка > N дней → автоблокировка + уведомление

**UC-48: Финансовый учёт и P&L**

- Автоматический расчёт P&L за день/неделю/месяц/квартал/год
- Доходы: выручка по заказам (автоматически из продаж)
- Себестоимость: из приходных документов (UC-64) — закупочная цена × проданное количество
- Расходы (вводятся вручную или автоматически):
  - Постоянные: аренда, связь, интернет (автоповтор каждый месяц)
  - Переменные: транспорт (газ), упаковка, тара
  - Налоги: УСН 6% от выручки (авторасчёт)
  - Списания/потери: из UC-62
- Чистая прибыль = Выручка − Себестоимость − Расходы − Налог
- Дашборд P&L: таблица + графики (выручка, маржа, прибыль по месяцам)
- Экспорт в Excel

#### СКЛАД / ПРИХОД

**UC-64: Приходование товара (через веб)**

- Админка → Склад → Новый приход
- Поля: поставщик (выбор из справочника или новый), дата, номер накладной
- Позиции: товар (из каталога), количество (кг), закупочная цена за кг
- Итого по приходу: сумма
- При проведении:
  - Остатки товаров увеличиваются
  - Себестоимость обновляется (средневзвешенная)
  - Данные уходят в 1С (поступление товара)
  - Закупочная цена логируется для истории
- Список всех приходов с фильтрами (дата, поставщик)

#### ПЛАТФОРМА

**UC-47: Уведомления и коммуникации**

- Каналы: Telegram (основной), Email, Push (PWA), SMS (резерв)
- Уведомления клиенту: новый статус заказа, документы готовы, оплата получена, кредитный лимит
- Уведомления админу: новый заказ, новый клиент на модерации, низкие остатки, просрочка оплаты
- Настройки: клиент выбирает каналы (Telegram/email/оба)
- Telegram-бот: /start → привязка аккаунта → получение уведомлений

**UC-51: Бэкап и безопасность**

- Ежедневный автобэкап MongoDB (mongodump) → S3/Яндекс.Облако
- Ежедневный бэкап загруженных файлов (сертификаты, документы)
- Ротация: 7 ежедневных + 4 еженедельных + 12 ежемесячных
- HTTPS everywhere (Let's Encrypt)
- Rate limiting на API (100 req/min для клиента, 1000 для админа)
- Input validation (Pydantic) на всех эндпоинтах
- CORS: только agrorezerv.ru и agroreserve.ru
- Логирование всех действий (audit trail — базовый)

#### МАРКЕТИНГ

**UC-46: SEO и контент**

- SSR/SSG для публичных страниц (каталог, товары) — для индексации поисковиками
- Meta теги: title, description, og:image для каждого товара и категории
- Sitemap.xml, robots.txt
- Микроразметка Schema.org (Product, Organization, LocalBusiness)
- Страница «О компании» с УТП, фото, реквизитами
- Страница «Для школ» — лендинг с калькулятором меню, преимуществами для 44-ФЗ
- Быстрая загрузка (Core Web Vitals): Lighthouse > 90
- Адаптивный дизайн (mobile-first)

#### АДМИНКА

**UC-11: Управление заказами**

- Список заказов с фильтрами: статус, дата, клиент, сумма
- Детали заказа: состав, клиент, адрес, документы
- Смена статуса: Новый → Подтверждён → Собирается → Собран → В пути → Доставлен / Отменён
- При смене статуса → автоуведомление клиенту (UC-47)
- При отгрузке: ввод фактического веса по каждой позиции (заказ 50 кг → факт 48.5 кг)

- Привязка сертификатов к товарам

**UC-58: Виджет «Сегодняшний день» (стартовая страница админа)**

- Блоки:
  - 💰 Финансы: выручка вчера/сегодня, оплаты, дебиторка, прибыль
  - 📦 Заказы: новые, к отгрузке, срочные
  - 🚚 Доставки на сегодня: список с адресами и временем

## ВАЖНЫЕ БИЗНЕС-ПРАВИЛА

1. **Цены:** B2B-клиенты видят оптовые цены, неавторизованные — розничные. Цены всегда за кг (или шт для штучных товаров)
2. **Фактический вес:** Заказ оформляется в примерном весе (50 кг), отгрузка — по факту (48.5 кг). Сумма пересчитывается по факту
3. **FIFO:** При отгрузке сначала уходит самая старая партия
4. **Себестоимость:** Средневзвешенная по всем приходам. Обновляется при каждом новом приходе
5. **УСН 6%:** Налог = 6% от выручки (не от прибыли). Считается автоматически в P&L
6. **Госконтракты:** Требуют полный пакет документов (ТОРГ-12, сертификаты, ярлыки). Сроки критичны — просрочка = штрафы
7. **Кредитный лимит:** Задолженность >= лимит → блокировка заказов. Просрочка > 30 дней → уведомление. > 60 дней → автоблокировка
8. **Минимальный остаток:** Товар ниже мин. остатка → алерт админу в Telegram + подсветка в дашборде
9. **Документы:** Все документы хранятся бессрочно. Нумерация сквозная по году
10. **Время работы:** Пн-Пт 08:00–17:00, Сб 08:00–14:00. Заказы принимаются 24/7 через сайт
